# Support

Use the narrowest support path that matches the problem.

## Usage And Setup

For local setup, validation, and development commands, start with [README.md](README.md) and
[CONTRIBUTING.md](CONTRIBUTING.md).

## Bugs

Open a GitHub issue for reproducible bugs in repository summary output, local path handling, package
scripts, validation workflow, or documentation.

Please include:

- Node.js version
- operating system
- command used
- expected and actual result
- a minimal public reproduction when possible

## Feature Proposals

Open a focused issue for new repository-health signals. Describe the adoption or debugging problem,
the proposed output shape, and how it can be tested deterministically.

## Security

Do not open public issues for suspected vulnerabilities. Follow [SECURITY.md](SECURITY.md) instead.
